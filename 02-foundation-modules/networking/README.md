# Foundation Module — Networking

*Revisited across Grades 6–11 with increasing complexity*

## Core concepts

- Network devices (routers, switches, modems)
- Network topologies
- LAN and WAN
- Wi-Fi
- IP addresses
- DNS and DHCP
- Protocols
- Troubleshooting
- Network security awareness

## Expected competency

A learner understands how devices communicate and how networks support digital services.

## Grade progression

| Grade | Focus |
|---|---|
| 6 | Internet connectivity awareness; devices that connect to networks |
| 7 | Cloud storage concepts; shared documents; how online collaboration reaches other devices |
| 8 | Meaning of networks; routers, switches, modems; wired and wireless networks; classroom network diagram |
| 9 | LAN/WAN; IP addresses; DNS awareness; network troubleshooting; small-school network design |
| 10 | Network architecture; DHCP; servers; virtualization; security; cloud and deployment concepts |
| 11 | Subnetting introduction; routing/switching; Linux fundamentals; troubleshooting documentation |

## Suggested practical activities

- Draw a network diagram for a classroom.
- Design a network for a small school or organization.
- Trace the path of a web request from device to website.
- Document a step-by-step network troubleshooting process.

## Mastery evidence

Learners identify network components, explain how devices communicate and design or troubleshoot a simple network.
