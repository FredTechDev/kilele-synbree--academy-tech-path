# Foundation Module — Hardware and Electronics

*Revisited across Grades 6–11 with increasing complexity*

## Core concepts

- Electricity and electrical safety
- Circuits and components
- Conductors and insulators
- Sensors and actuators
- Microcontrollers
- Programming hardware
- Automation
- Robotics

## Expected competency

A learner understands how physical computing systems interact with their environment.

## Grade progression

| Grade | Focus |
|---|---|
| 6 | Computer hardware; input/output devices; safe device handling |
| 7 | Storage devices and peripherals; removable media; backups |
| 8 | Electrical safety; circuits; voltage/current; resistors, LEDs, sensors; microcontrollers; simple LED circuit |
| 9 | Sensors and actuators; automation; simple robotics exploration |
| 10 | Programming microcontrollers; digital I/O; IoT concepts; environmental monitoring prototype |
| 11 | Circuit design; embedded programming; IoT architecture; capstone hardware projects |

## Safety

All practical electronics work must use safe, low-voltage educational equipment and teacher supervision. Electrical safety is taught before any circuit activity.

## Suggested practical activities

- Label computer hardware and classify components.
- Build a supervised LED circuit using educational equipment.
- Build or simulate a simple automated system.
- Develop a sensor-based environmental monitoring prototype.

## Mastery evidence

Learners build safe, working circuits or simulations and explain how sensors, controllers and actuators interact.
