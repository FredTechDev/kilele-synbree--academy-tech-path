# Foundation Module — Digital Productivity

*Revisited across Grades 6–11 with increasing complexity*

## Core concepts

- Word processing
- Spreadsheets
- Presentations
- Email
- Cloud storage
- Shared documents
- Collaboration
- Digital organization

## Expected competency

A learner can use digital applications to organize information, communicate and complete school-related tasks.

## Grade progression

| Grade | Focus |
|---|---|
| 6 | Typing; text formatting; headings; lists; basic documents; save and retrieve |
| 7 | Document formatting; tables; images; headers/footers; formulas (SUM, AVERAGE, MIN, MAX); charts; email etiquette; shared documents |
| 8 | Data validation; basic forms; simple records design; digital posters and presentations |
| 9 | Spreadsheet analysis; referencing; collaborative documents; project documentation |
| 10 | Reporting; analysis outputs; team-based collaboration tools |
| 11 | Technical reports; portfolio documentation; professional presentations |

## Suggested practical activities

- Create a properly formatted one-page school report.
- Build a classroom expenses spreadsheet with formulas and a chart.
- Prepare a presentation about technology in the community.
- Write a sample formal email with a subject line and attachment.

## Mastery evidence

Learners produce well-organized, correctly formatted documents and spreadsheets and communicate appropriately in digital spaces.
