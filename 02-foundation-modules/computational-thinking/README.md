# Foundation Module — Computational Thinking

*Revisited across Grades 6–11 with increasing complexity*

## Core concepts

- Decomposition
- Pattern recognition
- Abstraction
- Algorithms
- Logical reasoning
- Flowcharts
- Pseudocode
- Debugging

## Expected competency

A learner can break down problems and design logical steps toward solving them.

## Grade progression

| Grade | Focus |
|---|---|
| 6 | Instructions; sequences; ordering; cause and effect; simple decisions; step-by-step problem-solving |
| 7 | Decomposition; pattern recognition; abstraction; algorithms; conditions; flowcharts; pseudocode |
| 8 | Algorithms and syntax; variables, conditions and loops in visual programming and Python |
| 9 | Functions, lists and dictionaries; error handling; debugging strategies |
| 10 | Testing basics; code organization; algorithm selection; debugging techniques |
| 11 | Structured problem analysis; design decisions; evaluating and improving solutions |

## Suggested practical activities

- Write instructions for preparing a meal; arrange scrambled instructions in order.
- Create a simple flowchart.
- Design an algorithm to determine whether a learner passed an examination.
- Debug a deliberately flawed program and explain the fixes.

## Mastery evidence

Learners decompose a problem, represent a solution with a flowchart or pseudocode and debug their own work.
