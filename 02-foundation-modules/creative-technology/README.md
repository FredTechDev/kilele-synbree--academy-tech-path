# Foundation Module — Creative Technology

*Revisited across Grades 6–11 with increasing complexity*

## Core concepts

- Digital graphics
- Typography
- Visual communication
- Photography
- Audio and video
- Animation
- Digital storytelling
- UI/UX design
- Prototyping

## Expected competency

A learner can use digital tools to communicate ideas creatively.

## Grade progression

| Grade | Focus |
|---|---|
| 6 | Draw and present ideas digitally; digital safety posters |
| 7 | Visual hierarchy; slide design; images; typography basics; visual communication |
| 8 | Graphic design; image formats; color; layout; digital storytelling; basic animation; awareness poster |
| 9 | Wireframes; prototypes; layout; navigation; accessibility; design feedback |
| 10 | User research; personas; user journeys; usability testing; design iteration; product thinking |
| 11 | Design thinking; responsive design; accessible interfaces; multimedia capstone projects |

## Suggested practical activities

- Design a poster promoting responsible technology use.
- Create a digital presentation with effective visual hierarchy.
- Create a wireframe and prototype for a school information application.
- Produce an educational animation or multimedia learning resource.

## Mastery evidence

Learners create clear, purposeful and accessible digital media and explain the design choices they made.
