# Foundation Module — Computer Literacy

*Revisited across Grades 6–11 with increasing complexity*

## Core concepts

- Computer architecture
- Hardware and software
- Operating systems
- Memory and storage
- Input and output
- File systems
- Basic troubleshooting
- Device maintenance

## Expected competency

A learner can operate a computer, identify its basic components and perform common computing tasks.

## Grade progression

| Grade | Focus |
|---|---|
| 6 | Types of computers; input/output devices; hardware vs software; starting/shutting down; files and folders |
| 7 | Advanced file management; backups; local, removable and cloud storage; file compression |
| 8 | Computer components in more depth; safe handling; introduction to circuits and peripherals |
| 9 | System troubleshooting; storage and file systems awareness; peripheral configuration |
| 10 | Operating system security; servers and virtualization awareness |
| 11 | OS security for chosen pathway; professional project organization and documentation |

## Suggested practical activities

- Label a computer diagram and classify components as input, processing, output or storage.
- Compare a laptop and desktop; describe where each is used.
- Create and organize a folder structure for schoolwork.
- Demonstrate safe startup/shutdown and basic troubleshooting steps.

## Mastery evidence

Learners demonstrate competence by independently operating a device, organizing files logically and explaining the role of major components.
