# Foundation Module — Data Literacy

*Revisited across Grades 6–11 with increasing complexity*

## Core concepts

- Data collection
- Data types and data quality
- Tables and records
- Spreadsheets
- Basic statistics
- Visualization
- Databases
- Data ethics

## Expected competency

A learner can organize information and draw reasonable conclusions from data.

## Grade progression

| Grade | Focus |
|---|---|
| 6 | Organizing information in tables and lists; recognizing data in daily life |
| 7 | Data vs information; records and fields; class records table; spreadsheet formulas and charts |
| 8 | Data types; data validation; primary key concepts; database management systems |
| 9 | Data cleaning; basic statistics; interpretation; SQL (SELECT/INSERT/UPDATE/DELETE); data visualizations |
| 10 | Descriptive statistics; Python data analysis; public dataset analysis; data ethics |
| 11 | Exploratory data analysis; model evaluation awareness; reporting; privacy and ethical handling |

## Suggested practical activities

- Create a classroom expenses spreadsheet with SUM/AVERAGE and a chart.
- Design a student records database on paper or with a beginner tool.
- Analyze a school attendance dataset.
- Analyze a public environmental or agricultural dataset and produce a report.

## Mastery evidence

Learners collect, clean and organize data, create accurate visualizations and communicate justified conclusions.
