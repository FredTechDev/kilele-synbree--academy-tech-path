# Foundation Module — Programming

*Revisited across Grades 6–11 with increasing complexity*

## Core concepts

- Variables and data types
- Operators
- Input and output
- Conditions
- Loops
- Functions
- Collections
- Error handling
- Testing
- Code organization

## Expected competency

A learner can write, understand, test and improve simple programs.

## Grade progression

| Grade | Focus |
|---|---|
| 6 | No formal programming — sequencing and instructions only |
| 7 | Visual programming: events, sequences, variables, conditions, loops, animation (e.g. Scratch) |
| 8 | Programming logic; introduction to Python — `print()`, `input()`, variables, operators, `if`/`else`, loops |
| 9 | Python foundations: functions, lists, dictionaries, strings, error handling, debugging; Git/GitHub history |
| 10 | Intermediate Python: scope, modules, file handling, exceptions, OOP introduction, testing, team workflow |
| 11 | Pathway-specific advanced development: architecture, APIs, databases, testing and deployment |

## Tools

Python, Thonny, Visual Studio Code, browser-based environments; Scratch/MakeCode for visual programming. See [Tools](../../08-resources/tools.md).

## Suggested practical activities

- Build an interactive animated story (visual programming).
- Create a calculator or quiz.
- Build a student grade calculator / grade management program.
- Develop an inventory management application.

## Mastery evidence

Learners write working programs, test them with different inputs, debug errors and explain their design decisions.
