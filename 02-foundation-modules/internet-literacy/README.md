# Foundation Module — Internet and Web Literacy

*Revisited across Grades 6–11 with increasing complexity*

## Core concepts

- Internet architecture awareness
- Web browsers
- Websites
- URLs and domains
- Search engines and search techniques
- Web hosting awareness
- HTTP and HTTPS awareness
- Online research
- Information verification

## Expected competency

A learner can find, evaluate and responsibly use online information.

## Grade progression

| Grade | Focus |
|---|---|
| 6 | Meaning of the internet; browsers vs search engines; supervised searching; websites |
| 7 | Keywords; introductory search operators; reliable sources; misinformation; fact-checking; copyright and attribution |
| 8 | Web concepts; HTML pages; how websites and web applications differ |
| 9 | HTML/CSS/JavaScript foundation; responsive design awareness; verifying AI-assisted research |
| 10 | HTTP awareness; frontend/backend concepts; API awareness; hosting and deployment |
| 11 | Pathway-specific web architecture, security and deployment; information verification in technical research |

## Suggested practical activities

- Perform a supervised search and explain the results.
- Research a community issue using multiple sources and produce a referenced report.
- Compare HTTP and HTTPS and explain why HTTPS matters.
- Verify a claim found online using a second independent source.

## Mastery evidence

Learners locate relevant information, judge reliability, cite sources and explain basic web infrastructure.
