# Challenge — Function Calculator (Grade 8)

**Level 2: Independent Practice** · Concepts: functions, arithmetic, lists

## Task

Copy `starter.py` to `solution.py`, then complete these functions:

- `add(a, b)` — return the sum of two numbers.
- `multiply(a, b)` — return the product of two numbers.
- `average(numbers)` — return the average of a list of numbers.

Do not use modules; write the logic yourself.

## Test

```bash
bash scripts/run-challenges.sh grade-8/function-calculator
```

## Hints

1. A function returns a value with the `return` keyword.
2. `sum(numbers)` adds every item in a list; `len(numbers)` counts the items.
3. Guard against an empty list by returning `0`.

## Level 3 — Creative extension

Add `greatest(numbers)` that returns the largest value without using `max()`, then add a small menu that lets a user choose an operation.

Record your extension in your project README and technology passport.
