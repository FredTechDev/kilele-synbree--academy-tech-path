# Assessment and Evaluation Framework

*Kilele TechPath — Programme Framework*

Assessment should measure knowledge, practical competence, creativity and problem-solving. It should **not rely entirely on written examinations**.

## Assessment categories

| Category | Suggested weighting |
|---|---:|
| Conceptual understanding | 20% |
| Practical exercises | 25% |
| Projects | 25% |
| Problem-solving challenges | 15% |
| Documentation and presentation | 10% |
| Reflection and participation | 5% |
| **Total** | **100%** |

These are proposed programme weightings and may be adapted to applicable school assessment requirements.

## Assessment methods

- Short quizzes
- Practical demonstrations
- Individual assignments
- Group projects
- Oral explanations
- Digital portfolios
- Research tasks
- Project presentations
- Peer reviews
- Self-reflection

## Practical project rubric (100 marks)

| Criterion | Marks |
|---|---:|
| Understanding of the problem | 15 |
| Planning and design | 15 |
| Technical implementation | 25 |
| Creativity and innovation | 10 |
| Testing and improvement | 15 |
| Documentation | 10 |
| Presentation | 10 |
| **Total** | **100** |

## Competency levels

Use the developmental scale from the [Competency Framework](competency-framework.md):

1. **Emerging** — recognizes basic concepts, needs significant guidance.
2. **Developing** — performs basic tasks with some assistance.
3. **Competent** — applies concepts independently to familiar problems.
4. **Proficient** — adapts knowledge to unfamiliar challenges.
5. **Advanced** — independently develops, evaluates and improves solutions.

These levels describe learning progress, not fixed intelligence or ability.

## Grade-level assessment emphasis

- **Grades 6–7:** observation, practical demonstrations, simple quizzes, documents and posters.
- **Grades 8–9:** working programs, web pages, recorded demonstrations, repository history, project reports.
- **Grades 10–11:** portfolio evidence, capstone documentation, testing evidence, presentations and reflections.

## Evidence to collect

See the [Technology Passport](../07-learner-portfolio/technology-passport.md): documents, presentations, source code, GitHub repositories, screenshots, prototypes, data reports, circuit diagrams, videos and written reflections.
