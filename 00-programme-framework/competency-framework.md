# Technology Competency Framework

*Kilele TechPath — Programme Framework*

All learners should progressively develop the following eleven competencies. Each is revisited at increasing complexity across Grades 6–11 (see [Foundation Modules](../02-foundation-modules/)).

## 5.1 Computer literacy

**Topics:** definition of a computer; types of computers; components; input, processing, output and storage devices; hardware and software; operating systems; desktop environments; file management; basic troubleshooting; device maintenance.

**Expected competency:** a learner can operate a computer, identify its basic components and perform common computing tasks.

## 5.2 Digital productivity

**Topics:** word processing; document formatting; tables and lists; spreadsheets; formulas and functions; data entry; charts; presentation design; email communication; collaborative documents; cloud storage.

**Expected competency:** a learner can use digital applications to organize information, communicate and complete school-related tasks.

## 5.3 Internet literacy

**Topics:** what the internet is; websites and web pages; browsers; search engines; search techniques; URLs and domains; online communication; cloud services; digital information evaluation; copyright and attribution.

**Expected competency:** a learner can find, evaluate and responsibly use online information.

## 5.4 Digital citizenship

**Topics:** digital footprints; online identity; privacy; password protection; cyberbullying; online harassment; digital etiquette; copyright; plagiarism; responsible communication; digital wellbeing.

**Expected competency:** a learner can participate responsibly and safely in digital environments.

## 5.5 Computational thinking

**Topics:** decomposition; pattern recognition; abstraction; algorithm design; logical reasoning; sequencing; decision-making; flowcharts; pseudocode; debugging.

**Expected competency:** a learner can break down problems and design logical steps toward solving them.

## 5.6 Programming

**Topics:** programming languages; variables; data types; operators; input and output; conditions; loops; functions; collections; error handling; debugging; basic software design.

**Expected competency:** a learner can write, understand, test and improve simple programs.

## 5.7 Data literacy

**Topics:** data and information; data collection; data types; tables; data organization; spreadsheets; basic statistics; charts; data interpretation; data privacy; introduction to databases.

**Expected competency:** a learner can organize information and draw reasonable conclusions from data.

## 5.8 Hardware and electronics

**Topics:** computer components; circuit basics; electrical safety; conductors and insulators; sensors; microcontrollers; input and output components; basic automation; robotics concepts.

**Expected competency:** a learner understands how physical computing systems interact with their environment.

## 5.9 Networking

**Topics:** computer networks; network types; wired and wireless communication; routers; switches; modems; IP addresses; network protocols; internet connectivity; basic troubleshooting.

**Expected competency:** a learner understands how devices communicate and how networks support digital services.

## 5.10 Artificial intelligence

**Topics:** meaning of AI; examples of AI; machine learning concepts; training data; AI-generated content; prompt literacy; AI limitations; bias and misinformation; responsible AI use; human oversight.

**Expected competency:** a learner can explain introductory AI concepts and evaluate AI-generated outputs critically.

## 5.11 Creative technology

**Topics:** digital graphics; typography; visual communication; photography; audio; video; animation; digital storytelling; UI/UX design; prototyping.

**Expected competency:** a learner can use digital tools to communicate ideas creatively.

## Competency levels (developmental scale)

| Level | Name | Description |
|---|---|---|
| 1 | Emerging | Recognizes basic concepts but requires significant guidance. |
| 2 | Developing | Performs basic tasks with some assistance. |
| 3 | Competent | Independently applies concepts to familiar problems. |
| 4 | Proficient | Adapts knowledge to unfamiliar challenges; strong practical understanding. |
| 5 | Advanced | Independently develops, evaluates and improves solutions; explains decisions. |

These levels describe **learning progress, not fixed intelligence or ability**.
