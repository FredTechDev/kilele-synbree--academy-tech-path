# Intermediate Projects

*Kilele TechPath — Practical Project Framework*

Projects suited to Grades 8–9 (Creation and Exploration stages), where learners begin building working digital products.

## Projects

### Python Calculator
A program that performs basic arithmetic using input and output.
- **Skills:** variables, operators, input/output, conditions
- **Tools:** Python (Thonny or VS Code)
- **Evidence:** source code plus sample test runs

### Quiz Application
An interactive quiz that scores answers and gives feedback.
- **Skills:** conditions, loops, variables, validation
- **Tools:** Python or visual programming
- **Evidence:** source code and demonstration

### Personal Webpage
A personal HTML page with headings, links, images and lists.
- **Skills:** HTML structure, elements, basic styling
- **Tools:** HTML editor and browser
- **Evidence:** published or saved web page

### Student Grade Calculator
A program that calculates grades from marks.
- **Skills:** input, arithmetic, conditions, loops
- **Tools:** Python
- **Evidence:** source code and test cases

### Attendance Spreadsheet
Track attendance with formulas, charts and summary statistics.
- **Skills:** formulas, filtering, charts, interpretation
- **Tools:** spreadsheet application
- **Evidence:** spreadsheet with analysis

### Student Records Database
A simple database of student records with fields and records.
- **Skills:** tables, records, fields, primary keys, basic SQL
- **Tools:** SQLite / DB Browser or beginner tool
- **Evidence:** database file and sample queries

### School Network Diagram
A labelled diagram of a classroom or school network.
- **Skills:** network devices, connectivity, documentation
- **Tools:** diagram tool or paper
- **Evidence:** annotated network diagram

### Digital Portfolio
A collection of the learner's work with descriptions and reflections.
- **Skills:** organization, documentation, presentation
- **Tools:** document, slides or simple website
- **Evidence:** portfolio document or site

### Simple Electronic Circuit
A supervised LED or sensor circuit using safe educational equipment.
- **Skills:** circuits, components, electrical safety
- **Tools:** Micro:bit/Arduino kit or circuit simulator
- **Evidence:** photo/simulation screenshot and circuit explanation
