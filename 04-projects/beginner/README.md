# Beginner Projects

*Kilele TechPath — Practical Project Framework*

Guided, short projects suited to Grades 6–7 (Awareness and Competence stages). Each project should include a hands-on activity and observable evidence of learning.

## Projects

### Digital Poster
Create a poster communicating a simple idea (e.g. technology safety or computer parts).
- **Skills:** visual communication, layout, typography
- **Tools:** word processor, presentation or drawing tool
- **Evidence:** exported poster image/PDF

### Personal Profile Document
Write and format a one-page personal introduction.
- **Skills:** typing, formatting, headings, lists
- **Tools:** word processor
- **Evidence:** saved document

### Class Budget Spreadsheet
Record classroom expenses using formulas and a simple chart.
- **Skills:** data entry, cell references, SUM/AVERAGE, charts
- **Tools:** spreadsheet application
- **Evidence:** spreadsheet file with formulas and chart

### Digital Presentation
Prepare a short presentation about technology in the community.
- **Skills:** slide organization, visual hierarchy, delivery
- **Tools:** presentation software
- **Evidence:** slides and a short oral presentation

### Interactive Scratch Story
Build an animated, interactive story using visual programming.
- **Skills:** events, sequences, conditions, loops
- **Tools:** Scratch or MakeCode
- **Evidence:** shared project or recorded demonstration

### Flowchart Exercises
Represent everyday algorithms as flowcharts.
- **Skills:** sequencing, decisions, algorithms
- **Tools:** paper or diagram tool
- **Evidence:** flowchart drawings

### Computer Component Identification
Label and describe computer hardware components.
- **Skills:** hardware identification, input/output classification
- **Tools:** diagram template or poster
- **Evidence:** labelled diagram

### Digital Safety Campaign
Create a poster or short presentation about safe online behavior.
- **Skills:** digital citizenship, communication
- **Tools:** presentation or design tool
- **Evidence:** campaign material
