# Advanced Projects

*Kilele TechPath — Practical Project Framework*

Projects suited to Grades 10–11 (Discovery and Direction stages), involving independent development, testing and documentation.

## Projects

### Inventory Management Application
A Python application to add, update, search and list inventory items, with file handling and error handling.
- **Pathways:** Software Engineering
- **Evidence:** repository, source code, test evidence, documentation

### Library Management System
A relational database and interface for books, members and loans.
- **Pathways:** Software Engineering, Data Science
- **Evidence:** database schema, queries, application demonstration

### Data Visualization Dashboard
Visualizations and a short analytical report from a real dataset.
- **Pathways:** Data Science
- **Evidence:** analysis code, charts, written report

### Responsive Website
A multi-page, accessible website that works on different screen sizes.
- **Pathways:** Software Engineering, UI/UX
- **Evidence:** live or local site, source repository, design notes

### Database-Driven Application
An application that reads and writes data through a database.
- **Pathways:** Software Engineering, Data Science
- **Evidence:** code, database, documentation and demonstration

### Robotics Prototype
A sensor-based or automated physical prototype (e.g. environmental monitoring).
- **Pathways:** Robotics and IoT
- **Evidence:** circuit/program, demonstration video, safety notes

### AI Demonstration
A beginner-friendly classification or prediction demonstration with evaluation.
- **Pathways:** AI, Data Science
- **Evidence:** notebook/code, dataset description, evaluation results

### Network Architecture Proposal
A designed network for an organization with addressing and security considerations.
- **Pathways:** Networking and Cloud
- **Evidence:** network diagram, addressing plan, troubleshooting notes

### Digital Product Prototype
A researched, tested and iterated prototype for a community problem.
- **Pathways:** UI/UX, Multimedia
- **Evidence:** personas, wireframes, prototype, usability test results
