# Interdisciplinary Projects

*Kilele TechPath — Practical Project Framework*

Learners should also work on projects combining different disciplines. These projects develop collaboration, systems thinking and real-world problem solving.

## Project A: Smart Agriculture

**Combines:** Robotics · Sensors · Programming · Data collection · Environmental awareness

Build a sensor-based prototype (e.g. soil moisture monitoring) that collects data and suggests actions for crop care.

## Project B: School Information System

**Combines:** Software development · Database management · UI/UX · Digital communication

Design and build a small system for school announcements, records or bookings, with an accessible interface.

## Project C: Environmental Data Explorer

**Combines:** Data analysis · Research · Visualization · Presentation

Collect or source environmental data, clean and analyze it, then communicate findings through visualizations and a report.

## Project D: Digital Safety Campaign

**Combines:** Cybersecurity · Multimedia · Communication · Digital citizenship

Research common online threats and produce an awareness campaign (posters, videos or a presentation) for the school community.

## Project E: Smart Classroom

**Combines:** Electronics · Networking · Programming · Automation

Prototype an automated classroom feature (e.g. lighting or air-quality alerts) with sensing, connectivity and a simple interface.

## Suggested workflow

1. Identify a real problem and target users.
2. Form a team and allocate roles.
3. Plan, design, build and test the solution.
4. Document decisions and evidence.
5. Present the project and reflect as a team and individually.

## Assessment

Use the [Practical Project Rubric](../../05-assessments/rubrics/README.md). Peer feedback and self-reflection are especially important for team projects.
