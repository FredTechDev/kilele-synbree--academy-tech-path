# Classroom Activities

*Kilele TechPath — Teacher Resources*

A bank of short, practical classroom activities that can be adapted across grades.

## Awareness and competence (Grades 6–7)

- **Technology scavenger hunt:** identify ten technologies used in everyday life.
- **Hardware labeling:** label a computer diagram and classify input, processing, output and storage.
- **Scrambled instructions:** arrange steps for a familiar task into the correct order, then write a flowchart.
- **Folder challenge:** create an organized folder structure for schoolwork with correct naming.
- **Safe/unsafe scenarios:** sort online situations into safe and unsafe categories and explain why.
- **Formula race:** build a simple spreadsheet with SUM and AVERAGE and interpret the results.

## Creation and exploration (Grades 8–9)

- **Algorithm to code:** turn a flowchart into a short visual program or Python script.
- **Debug the bug:** find and fix errors in a provided program; explain each fix.
- **Tag hunt:** find HTML elements in a page and identify their tags.
- **Network mapping:** draw how devices connect in a classroom, labeling router, switch and modem.
- **Phishing detective:** examine simulated messages and list warning signs.
- **AI fact-check:** compare an AI-generated explanation with a reliable source and evaluate accuracy.

## Discovery and direction (Grades 10–11)

- **Pathway stations:** rotate through short demonstrations of each specialization pathway.
- **SQL practice:** write SELECT, INSERT, UPDATE and DELETE queries against a sample database.
- **Security lab:** identify weaknesses in an isolated training environment and write defensive recommendations.
- **Sensor challenge:** build a simple sensor-based prototype and record readings.
- **Wireframe sprint:** sketch a wireframe, get peer feedback and iterate.
- **Code review circle:** learners explain code to peers and suggest improvements.

## Activity design tips

- Always state the learning objective and success criteria.
- Keep the practical component central — every major topic needs a hands-on activity.
- Use real-world contexts from learners' environments.
- Prepare an offline alternative for limited connectivity.
- Finish with a short reflection: *What did I learn? What would I improve?*

## Safety

All cybersecurity and electronics activities must be supervised, simulated or explicitly authorized and use safe educational equipment.
