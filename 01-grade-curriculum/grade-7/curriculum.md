# Grade 7 — Develop Digital Competence

**Stage:** Competence · **Theme:** Becoming digitally productive

> *Kilele TechPath — Grade 7 Curriculum*

## Grade overview

Grade 7 builds on basic computer literacy and introduces learners to digital productivity, structured information, online collaboration and introductory computational thinking.

## Learning outcomes

Learners should be able to:

- Organize digital information.
- Create formatted documents.
- Use basic spreadsheet functions.
- Design presentations.
- Communicate using email under appropriate supervision.
- Search for reliable information.
- Explain basic copyright and plagiarism.
- Create simple algorithms.
- Draw flowcharts.
- Understand basic visual programming.

## Modules

### Module 1: Advanced file management

**Topics:** folder organization; file extensions; file compression; backups; local storage; removable storage; cloud storage concepts.

**Practical:** organize a digital school portfolio with separate folders for subjects and assignments.

### Module 2: Word processing

**Topics:** document formatting; fonts and typography; headings; page layout; tables; images; headers and footers; page numbering; exporting documents.

**Practical:** create a properly formatted school report.

### Module 3: Spreadsheets

**Topics:** rows and columns; cells; cell references; data entry; basic formulas; SUM, AVERAGE, MIN, MAX; sorting; filtering; basic charts.

**Practical:** create a classroom expenses spreadsheet.

### Module 4: Presentation design

**Topics:** slide organization; visual hierarchy; text and images; charts; transitions; presentation delivery; visual communication.

**Practical:** prepare a presentation about technology in the community.

### Module 5: Digital communication

**Topics:** email; subject lines; attachments; formal communication; online collaboration; digital etiquette; shared documents.

**Practical:** prepare a sample formal email and collaborative class document.

### Module 6: Internet research

**Topics:** search engines; keywords; introductory search operators; reliable sources; misinformation; fact-checking; copyright; plagiarism; attribution.

**Practical:** research a community issue using multiple sources and prepare a referenced report.

### Module 7: Introduction to databases

**Topics:** meaning of data and information; records; fields; tables; categories; structured information; introduction to relational data.

**Practical:** create a simple class records table.

### Module 8: Computational thinking

**Topics:** decomposition; pattern recognition; abstraction; algorithms; sequencing; conditions; flowcharts; pseudocode.

**Practical:** design an algorithm for determining whether a learner has passed an examination.

### Module 9: Introduction to visual programming

**Topics:** programming environments; events; instructions; sequences; variables; conditions; loops; basic animation; interactive projects.

**Suggested environment:** Scratch or another age-appropriate visual programming tool.

**Practical:** build an interactive animated story.

### Module 10: Digital responsibility

**Topics:** digital identity; privacy; password hygiene; cyberbullying; copyright; digital wellbeing; responsible online participation.

**Practical:** develop a classroom digital citizenship guide.

## Practical projects

1. Class Budget Spreadsheet
2. Personal Digital Profile
3. Interactive Scratch Story
4. School Research Presentation
5. Digital Records Organizer

## Expected outcome

The learner can use technology productively, organize information, communicate digitally and solve simple problems through structured logic.
