# Grade 10 — Discover Technology Pathways

**Stage:** Discovery · **Theme:** Exploring specialization pathways

> *Kilele TechPath — Grade 10 Curriculum*

## Grade overview

Grade 10 introduces more focused exploration of technology specializations.

Learners should understand the different disciplines, experience their practical activities and identify areas they want to investigate further.

The purpose is **not** to permanently assign learners to careers but to provide informed choices.

## Learning outcomes

Learners should be able to:

- Develop intermediate programs.
- Build more complete websites.
- Understand application development.
- Work with structured databases.
- Perform introductory data analysis.
- Explore cybersecurity in controlled laboratories.
- Design digital product prototypes.
- Understand AI and machine learning workflows.
- Explore robotics and IoT.
- Understand cloud computing concepts.
- Work collaboratively on technology projects.
- Identify preferred specialization pathways.

## Modules

### Module 1: Intermediate programming

**Topics:** functions; scope; modules; collections; file handling; exception handling; object-oriented programming introduction; code organization; testing basics; debugging techniques.

**Practical:** develop a Python-based inventory management application.

### Module 2: Web application development

**Topics:** HTML; CSS; JavaScript; DOM manipulation; forms; validation; responsive interfaces; HTTP awareness; frontend and backend concepts; API awareness.

**Practical:** build an interactive school information website.

### Module 3: Database and SQL development

**Topics:** relational databases; database design; tables and relationships; primary and foreign keys; SQL queries; joins; constraints; data validation; database security awareness.

**Practical:** design and implement a library management database.

### Module 4: Data analysis

**Topics:** data collection; data cleaning; descriptive statistics; spreadsheet analysis; Python data analysis; data visualization; interpretation; reporting; data ethics.

**Practical:** analyze a public environmental or agricultural dataset.

### Module 5: Cybersecurity exploration

**Topics:** security principles; confidentiality, integrity and availability; authentication; access control; network security; web security awareness; vulnerability concepts; threat modeling; defensive monitoring; incident response awareness.

**Practical:** use a deliberately vulnerable, isolated training environment to identify basic security weaknesses and document defensive recommendations.

> All testing must occur on systems the learner owns or has explicit permission to test.

### Module 6: UI/UX and product design

**Topics:** user research; personas; user journeys; wireframes; prototypes; visual hierarchy; accessibility; usability testing; design iteration; product thinking.

**Practical:** design and test a prototype for a community problem.

### Module 7: Artificial intelligence exploration

**Topics:** AI fundamentals; machine learning concepts; training and testing data; classification; prediction; model evaluation awareness; natural language processing awareness; generative AI; bias; responsible AI.

**Practical:** build or explore a beginner-friendly classification demonstration using a safe educational dataset.

### Module 8: Robotics and IoT

**Topics:** microcontrollers; sensors; actuators; programming hardware; digital input and output; automation; IoT concepts; device communication; physical computing safety.

**Practical:** develop a sensor-based environmental monitoring prototype.

### Module 9: Networking and cloud computing

**Topics:** network architecture; IP addressing; DNS; DHCP; network security; servers; virtualization concepts; cloud computing; cloud storage; hosting; deployment concepts.

**Practical:** design a small organization network and explore deploying a simple static website.

### Module 10: Software engineering practices

**Topics:** requirements; project planning; software development lifecycle; Git branching; code review; testing; documentation; issue tracking; team collaboration; software quality.

**Practical:** develop a small application using a team-based workflow.

### Module 11: Technology entrepreneurship

**Topics:** identifying problems; innovation; product ideas; user needs; market awareness; prototyping; value propositions; basic business models; presentations; responsible innovation.

**Practical:** create a technology solution proposal for a local challenge.

## Specialization exploration

Every learner should receive introductory exposure to the available pathways:

- Software engineering: one practical project
- Data science: one data analysis exercise
- Cybersecurity: one defensive security exercise
- AI: one introductory AI experiment
- Robotics: one hardware or simulation project
- UI/UX: one interface prototype
- Networking and cloud: one network design or deployment exercise
- Multimedia: one digital storytelling project

See [Specialization Pathways](../../03-specialization-pathways/) and the [Grade 11 pathways](../grade-11/curriculum.md).

## Practical projects

1. Inventory Management Application
2. Library Database System
3. Data Analysis Report
4. Digital Product Prototype
5. Cybersecurity Awareness Laboratory
6. IoT Environmental Monitoring Demonstration
7. Cloud-Hosted Website
8. Technology Innovation Proposal

## Expected outcome

The learner has meaningful experience across technology disciplines and can identify personal interests, strengths and potential specialization directions.
