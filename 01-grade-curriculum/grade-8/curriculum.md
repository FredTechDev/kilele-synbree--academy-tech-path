# Grade 8 — Understand and Create

**Stage:** Creation · **Theme:** Understanding how technology works

> *Kilele TechPath — Grade 8 Curriculum*

## Grade overview

Grade 8 introduces learners to how digital systems operate and how software is created.

Learners transition from using applications to building simple digital products.

## Learning outcomes

Learners should be able to:

- Explain basic programming concepts.
- Design simple algorithms.
- Use variables and conditions.
- Understand loops.
- Write simple programs.
- Create basic HTML pages.
- Understand introductory databases.
- Identify common network devices.
- Explain basic electronics.
- Describe introductory AI concepts.

## Modules

### Module 1: Introduction to programming

**Topics:** meaning of programming; programming languages; source code; instructions; syntax; errors; algorithms; programming environments.

**Practical:** write a simple sequence of instructions and translate it into a visual programming project.

### Module 2: Programming logic

**Topics:** variables; data types; input; output; operators; conditions; loops; functions; debugging.

**Practical:** create a basic calculator or quiz using a suitable beginner programming environment.

### Module 3: Introduction to Python

**Topics:** installing or accessing Python; running Python programs; `print()`, `input()`; variables; numbers; strings; basic arithmetic; comparison operators; `if`/`else`; `for` and `while` loops.

**Practical:** build a simple student grade calculator.

### Module 4: Introduction to web development

**Topics:** what the web is; websites and web applications; HTML; elements and tags; headings; paragraphs; links; images; lists; basic forms.

**Practical:** build a personal HTML webpage.

### Module 5: Data and databases

**Topics:** data types; data collection; data validation; tables; records; fields; primary key concepts; introduction to database management systems.

**Practical:** design a simple student records database on paper or using an appropriate beginner tool.

### Module 6: Introduction to computer networks

**Topics:** meaning of networks; network devices — routers, switches, modems; wired and wireless networks; Wi-Fi; internet connectivity.

**Practical:** draw a network diagram for a classroom.

### Module 7: Hardware and electronics

**Topics:** electrical safety; basic circuits; voltage; current; conductors and insulators; resistors; LEDs; sensors; microcontrollers.

**Practical:** create a supervised LED circuit using safe educational equipment.

### Module 8: Robotics and automation

**Topics:** meaning of robotics; robots in everyday life; sensors; actuators; controllers; automation; basic movement and control logic.

**Practical:** build or simulate a simple automated system.

### Module 9: Introduction to artificial intelligence

**Topics:** meaning of AI; examples of AI; machine learning awareness; data and AI; AI-generated content; AI limitations; bias; responsible use.

**Practical:** compare human-generated and AI-generated explanations and evaluate their accuracy.

### Module 10: Digital creativity

**Topics:** graphic design; image formats; typography; color; layout; digital storytelling; basic animation.

**Practical:** design a poster promoting responsible technology use.

## Practical projects

1. Python Calculator
2. Interactive Quiz
3. Personal HTML Website
4. Classroom Network Diagram
5. Basic Electronic Circuit
6. Digital Awareness Poster

## Expected outcome

The learner can create simple digital solutions and understands the basic principles behind programming, web development, data, networks and physical computing.
