# Grade 9 — Explore the Technology Ecosystem

**Stage:** Exploration · **Theme:** Exploring the technology ecosystem

> *Kilele TechPath — Grade 9 Curriculum*

## Grade overview

Grade 9 introduces learners to the broader technology ecosystem.

The focus is on developing practical confidence across multiple disciplines while introducing collaborative development and project documentation.

## Learning outcomes

Learners should be able to:

- Write basic Python programs.
- Develop simple web pages.
- Understand HTML, CSS and introductory JavaScript.
- Use Git for basic version control.
- Understand GitHub repositories.
- Interpret simple datasets.
- Create basic data visualizations.
- Understand cybersecurity principles.
- Design basic user interfaces.
- Explore robotics and AI.
- Collaborate on projects.
- Document their work.

## Modules

### Module 1: Python programming foundations

**Topics:** variables; data types; input and output; operators; conditions; loops; functions; lists; dictionaries; strings; basic error handling; debugging.

**Practical:** build a student grade management program.

### Module 2: Web development foundations

**Topics:** HTML structure; semantic HTML; CSS; selectors; colors; typography; layout; Flexbox introduction; responsive design awareness; JavaScript introduction; events; DOM awareness.

**Practical:** build a responsive personal portfolio webpage.

### Module 3: Version control

**Topics:** meaning of version control; Git; GitHub; repositories; commits; staging; branches; merging; remote repositories; cloning; pulling; pushing; basic conflict resolution.

**Practical:** publish a Python project to GitHub and maintain its history.

### Module 4: Data analysis foundations

**Topics:** data collection; data cleaning; data organization; spreadsheet analysis; basic statistics; charts; data interpretation; introduction to Python data analysis.

**Practical:** analyze a sample school attendance dataset.

### Module 5: Database foundations

**Topics:** database concepts; tables; records; fields; primary keys; relationships; basic SQL — SELECT, INSERT, UPDATE, DELETE; database safety.

**Practical:** create a basic student records database.

### Module 6: Cybersecurity awareness

**Topics:** cybersecurity concepts; authentication; password protection; multi-factor authentication; phishing; malware awareness; social engineering; data protection; safe browsing; backups.

**Practical:** analyze simulated phishing messages and create a cybersecurity awareness guide.

### Module 7: UI/UX introduction

**Topics:** user experience; user interface; user needs; wireframes; prototypes; layout; navigation; accessibility; design feedback.

**Practical:** create a prototype for a school information application.

### Module 8: Networking foundations

**Topics:** network types; LAN; WAN; IP addresses; routers; switches; DNS awareness; internet protocols; network troubleshooting; network security awareness.

**Practical:** design a network for a small school.

### Module 9: AI and automation exploration

**Topics:** AI applications; machine learning awareness; data in AI systems; prompt writing; AI-assisted productivity; AI accuracy; responsible AI; simple automation concepts.

**Practical:** use an approved AI tool to support a supervised research task, then verify its output.

### Module 10: Technology teamwork

**Topics:** project planning; task allocation; collaboration; documentation; GitHub teamwork; communication; peer feedback; presentation.

**Practical:** work in teams to develop a small digital solution.

## Practical projects

1. Personal Portfolio Website
2. Python Student Grade Calculator
3. School Attendance Data Analysis
4. Student Records Database
5. School Network Design
6. Cybersecurity Awareness Campaign
7. Collaborative GitHub Project

## Expected outcome

The learner understands the major technology disciplines and has practical experience with programming, data, web development, networking, cybersecurity, design and collaboration.
