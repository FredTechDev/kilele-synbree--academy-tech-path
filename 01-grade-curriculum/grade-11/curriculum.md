# Grade 11 — Build and Specialize

**Stage:** Direction · **Theme:** Building and developing focused expertise

> *Kilele TechPath — Grade 11 Curriculum*

## Grade overview

Grade 11 provides deeper practical exposure and allows learners to concentrate on selected technology pathways.

Each learner should select:

- One primary specialization.
- One complementary area.
- A practical capstone project.

The learner should continue to develop general digital responsibility, problem-solving and collaboration skills regardless of specialization.

## Learning outcomes

Learners should be able to:

- Develop structured technical projects.
- Apply suitable tools within their selected pathway.
- Design and test solutions.
- Document development processes.
- Collaborate using version control.
- Present technical work.
- Evaluate project quality.
- Reflect on strengths and learning goals.
- Build a technology portfolio.

## Shared technical foundation

All learners study:

### Project development
Problem identification; requirements gathering; planning; design; implementation; testing; evaluation; documentation; presentation.

### Software and digital collaboration
Git; GitHub; branching; pull requests; code review; issue tracking; documentation; project organization.

### Data and information management
Structured data; data validation; privacy; security; ethical data handling.

### Technical communication
Technical writing; project reports; demonstrations; presentations; peer review; professional communication.

## Capstone project

Every learner completes one substantial project demonstrating their selected pathway.

Required deliverables:

1. Project title
2. Problem statement
3. Background and motivation
4. Target users
5. Requirements
6. Design or architecture
7. Tools and technologies
8. Implementation or prototype
9. Testing and evaluation
10. Challenges encountered
11. Improvements
12. Project documentation
13. Final presentation
14. Reflection on learning

Use the [Project Template](../../07-learner-portfolio/project-template.md) and [Reflection Template](../../07-learner-portfolio/reflection-template.md).

## Assessment emphasis

- Portfolio evidence and capstone documentation
- Testing evidence and working implementation/prototype
- Technical presentation and peer review
- Competency levels 3–5 expected at this stage

## Expected outcome

The learner possesses a clear technology direction, practical experience, a documented portfolio and the ability to continue developing technical skills independently.
