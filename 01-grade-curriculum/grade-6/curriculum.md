# Grade 6 — Discover Technology

**Stage:** Awareness · **Theme:** Discovering the digital world

> *Kilele TechPath — Grade 6 Curriculum*

## Grade overview

Grade 6 introduces learners to technology and establishes confidence in using digital devices.

The objective is to help learners understand what computers are, how they work at a basic level and how technology supports everyday activities.

## Learning outcomes

By the end of Grade 6, learners should be able to:

- Define technology and computing.
- Identify common computing devices.
- Recognize computer hardware components.
- Distinguish hardware from software.
- Explain input, processing, output and storage.
- Operate a basic computer environment.
- Create and organize files and folders.
- Use a keyboard and mouse.
- Create a basic digital document.
- Navigate a web browser.
- Identify basic online safety risks.
- Develop simple step-by-step instructions.

## Modules

### Module 1: Introduction to technology

**Topics:** meaning of technology; technology in everyday life, schools, homes and businesses; positive and negative effects of technology; examples of digital devices.

**Activities:** identify ten technologies used in everyday life; discuss how technology helps farmers, teachers and doctors; draw a timeline of changes in communication technology.

### Module 2: Introduction to computers

**Topics:** meaning of a computer; types of computers — desktops, laptops, tablets, smartphones, servers; basic computer operations.

**Activities:** identify different computer devices; compare a laptop and desktop; describe where computers are used.

### Module 3: Computer hardware

**Topics:** monitor, keyboard, mouse, system unit, processor, memory, storage, speakers, printer, microphone, camera.

**Activities:** label a computer diagram; identify input and output devices; explain the function of selected components.

### Module 4: Understanding software

**Topics:** meaning of software; system software; application software; operating systems; utility software; examples of common applications.

**Activities:** identify applications on a computer; classify software by purpose; compare an operating system with a word processor.

### Module 5: Computer operation

**Topics:** starting and shutting down a computer; desktop navigation; windows and application management; keyboard shortcuts; mouse operations; basic troubleshooting.

**Activities:** open and close applications; create a folder; rename a file; save and retrieve a document.

### Module 6: File management

**Topics:** files and folders; file names; file extensions; saving, copying, moving, renaming and deleting; Recycle Bin or Trash; storage locations.

**Activities:** create an organized schoolwork folder; save a document in the correct location; identify common file extensions.

### Module 7: Basic digital productivity

**Topics:** introduction to word processing; typing; text formatting; paragraphs; headings; lists; document saving.

**Activities:** create a personal introduction; format a one-page school document; create a simple class notice.

### Module 8: Internet awareness

**Topics:** meaning of the internet; websites; web browsers; search engines; basic web navigation; online information; internet connectivity.

**Activities:** identify common websites; perform a supervised search; explain the difference between a browser and a search engine.

### Module 9: Digital safety

**Topics:** personal information; passwords; suspicious links; online strangers; cyberbullying; safe communication; asking trusted adults for assistance.

**Activities:** identify safe and unsafe online scenarios; create a digital safety poster; practice identifying suspicious messages.

### Module 10: Introduction to logical thinking

**Topics:** instructions; sequences; ordering; cause and effect; simple decisions; step-by-step problem-solving.

**Activities:** write instructions for preparing a meal; arrange scrambled instructions in the correct order; create a simple flowchart.

## Practical projects

5. Step-by-Step Instructions Challenge

## Assessment

Assessment should evaluate:

- Basic computer operation
- Hardware identification
- File management
- Document creation
- Internet awareness
- Digital safety
- Logical sequencing

## Expected outcome

The learner becomes confident using digital devices and understands fundamental computing concepts.
