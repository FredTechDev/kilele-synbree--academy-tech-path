# Pathway A — Software Engineering

**Primary interest:** Building software and applications

*Grade 11 primary specialization pathway · Kilele TechPath*

## Overview

Learners in this pathway design, build, test and document software applications. They progress from writing programs to managing complete projects using professional development practices.

## Topics

- Programming language fundamentals
- Advanced functions
- Object-oriented programming
- Data structures introduction
- Algorithms
- Web application architecture
- Frontend development
- Backend development
- API development
- Database integration
- Authentication concepts
- Testing
- Debugging
- Deployment
- Software documentation

## Suggested technologies

Python · JavaScript · HTML · CSS · SQL · Git · GitHub

## Runnable example

A working version of this demonstration is provided in [09-code-examples](../../09-code-examples/README.md): [Student Grade Calculator](../../09-code-examples/01-software-engineering/student-grade-calculator.py).
Run it, change its inputs, then extend it into a capstone project.

## Capstone examples

- School management application
- Library management system
- Student performance tracker
- Community service platform
- Inventory management system

## Grade 10 exploration

Before specialization, learners complete one practical software project (e.g. an inventory management application) and take part in a team-based workflow using requirements, planning, Git branching, code review and testing.

## Suggested capstone deliverables

Working application with source code in a repository, requirements and design documentation, test evidence, deployment or demonstration, and a personal reflection. Use the [Project Template](../../07-learner-portfolio/project-template.md).
