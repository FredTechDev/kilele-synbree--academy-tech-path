# Pathway C — Cybersecurity

**Primary interest:** Protecting systems and information

*Grade 11 primary specialization pathway · Kilele TechPath*

## Overview

Learners in this pathway study how to protect systems, networks and information, focusing on defensive security, risk assessment and responsible practice.

## Topics

- Security fundamentals
- Threat identification
- Authentication
- Access control
- Operating system security
- Network security
- Web security awareness
- Encryption concepts
- Secure passwords
- Security monitoring
- Risk assessment
- Incident response
- Ethical hacking principles
- Defensive security documentation

## Suggested technologies

Linux · Networking tools · Virtual machines · Browser security tools · Approved cybersecurity training laboratories

## Capstone examples

- School cybersecurity awareness system
- Security assessment of a controlled demonstration environment
- Password safety education campaign
- Basic network security plan

## Grade 10 exploration

Before specialization, learners use a deliberately vulnerable, isolated training environment to identify basic weaknesses and document defensive recommendations.

## ⚠️ Ethics and authorization

> Access to a computer system does **not** automatically grant permission to test or modify it.

All testing must occur on systems the learner owns or has explicit permission to test. Activities must use teacher-approved exercises, simulated environments, educational laboratories, or explicitly authorized environments. Never scan, probe or test systems without written authorization.
