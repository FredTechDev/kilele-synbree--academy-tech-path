# Pathway D — Artificial Intelligence and Machine Learning

**Primary interest:** Developing intelligent systems

*Grade 11 primary specialization pathway · Kilele TechPath*

## Overview

Learners in this pathway explore how systems learn from data, build simple models and evaluate their behavior critically and responsibly.

## Topics

- AI concepts
- Machine learning
- Data preparation
- Training and testing data
- Classification
- Regression awareness
- Model evaluation
- Neural network awareness
- Natural language processing
- Generative AI
- Prompt engineering
- AI ethics
- Bias
- Privacy
- Human oversight

## Suggested technologies

Python · Jupyter · Educational machine learning tools · Approved AI services

## Capstone examples

- Simple image classification demonstration
- Educational recommendation prototype
- Data-based prediction experiment
- AI-assisted learning prototype

## Grade 10 exploration

Before specialization, learners build or explore a beginner-friendly classification demonstration using a safe educational dataset.

## Responsible AI

AI can make mistakes and may reflect bias in its training data. Verify outputs, avoid sharing personal information, keep a human in the loop and maintain academic integrity.
