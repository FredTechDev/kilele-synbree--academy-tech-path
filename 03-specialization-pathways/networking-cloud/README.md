# Pathway G — Networking and Cloud Computing

**Primary interest:** Connecting and managing digital infrastructure

*Grade 11 primary specialization pathway · Kilele TechPath*

## Overview

Learners in this pathway design, configure, troubleshoot and secure networks and explore cloud hosting and deployment.

## Topics

- Network fundamentals
- IP addressing
- Subnetting introduction
- DNS
- DHCP
- Routing
- Switching
- Network troubleshooting
- Linux fundamentals
- Servers
- Virtualization
- Cloud architecture
- Hosting
- Deployment
- Backup strategies
- Security fundamentals

## Suggested technologies

Linux · Cisco Packet Tracer · Virtual machines · Cloud education environments · Git and GitHub

## Runnable example

A working version of this demonstration is provided in [09-code-examples](../../09-code-examples/README.md): [IP Address Information Tool](../../09-code-examples/07-networking-cloud/ip-address-tool.py).
Run it, change its inputs, then extend it into a capstone project.

## Capstone examples

- School network architecture
- Small organization infrastructure design
- Hosted website deployment
- Network troubleshooting documentation

## Grade 10 exploration

Before specialization, learners design a small organization network and explore deploying a simple static website.
