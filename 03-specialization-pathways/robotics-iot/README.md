# Pathway E — Robotics and Internet of Things

**Primary interest:** Building connected physical systems

*Grade 11 primary specialization pathway · Kilele TechPath*

## Overview

Learners in this pathway combine electronics, programming and data to build physical systems that sense and respond to their environment.

## Topics

- Electronics
- Microcontrollers
- Sensors
- Actuators
- Circuit design
- Embedded programming
- Automation
- Robotics logic
- Device communication
- IoT architecture
- Data collection
- Hardware safety

## Suggested technologies

Arduino · Micro:bit · Raspberry Pi where available · Educational circuit simulators · Python or C/C++

## Capstone examples

- Smart irrigation demonstration
- Environmental monitoring device
- Automated lighting prototype
- Smart classroom demonstration

## Grade 10 exploration

Before specialization, learners develop a sensor-based environmental monitoring prototype.

## Safety

Use low-voltage educational equipment and teacher supervision. Electrical safety must be understood before practical circuit work, and connected devices must be configured securely.
