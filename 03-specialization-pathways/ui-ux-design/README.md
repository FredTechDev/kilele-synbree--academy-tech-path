# Pathway F — UI/UX and Digital Product Design

**Primary interest:** Creating useful digital experiences

*Grade 11 primary specialization pathway · Kilele TechPath*

## Overview

Learners in this pathway research user needs and design accessible, usable and attractive digital products through iterative prototyping.

## Topics

- Design thinking
- User research
- User personas
- User journeys
- Wireframing
- Prototyping
- Visual hierarchy
- Typography
- Color theory
- Responsive design
- Accessibility
- Usability testing
- Product iteration
- Design documentation

## Suggested technologies

Figma · Pen-and-paper wireframes · Graphic design tools · HTML and CSS awareness

## Capstone examples

- School application prototype
- Educational mobile interface
- Community information portal
- Accessible learning platform prototype

## Grade 10 exploration

Before specialization, learners design and test a prototype for a community problem using user research, personas, wireframes and usability testing.

## Design principles

Design for real user needs, prioritize clarity and accessibility, test with users and iterate based on feedback. Include captions, contrast and keyboard accessibility where possible.
