# Pathway B — Data Science and Analytics

**Primary interest:** Understanding and interpreting data

*Grade 11 primary specialization pathway · Kilele TechPath*

## Overview

Learners in this pathway collect, clean, analyze and visualize data to answer questions and communicate evidence-based conclusions.

## Topics

- Data collection
- Data quality
- Data cleaning
- Descriptive statistics
- Data visualization
- Spreadsheet analysis
- SQL
- Python
- Exploratory data analysis
- Introductory machine learning
- Model evaluation
- Data ethics
- Reporting

## Suggested technologies

Python · Pandas · Matplotlib · Jupyter · SQL · Spreadsheet applications

## Capstone examples

- School attendance analysis
- Agricultural data analysis
- Community environmental report
- Student performance dashboard

## Grade 10 exploration

Before specialization, learners analyze a public environmental or agricultural dataset, applying data cleaning, descriptive statistics, visualization and ethical considerations.

## Suggested capstone deliverables

A clearly defined research question, cleaned dataset, analysis code, appropriate visualizations, a written report and a presentation. Personal or sensitive data must be handled ethically and privately. Use the [Project Template](../../07-learner-portfolio/project-template.md).
