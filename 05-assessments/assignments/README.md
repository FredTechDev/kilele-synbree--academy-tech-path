# Assignments

*Kilele TechPath — Assessment and Evaluation Framework*

Assignments are individual or group tasks completed over a longer period, such as research tasks, documents, reports and project work.

## Assignment types

- **Documents and presentations** — formatted reports, posters, slide decks.
- **Research tasks** — questions investigated using multiple reliable sources with attribution.
- **Programming tasks** — code with test evidence and a short explanation.
- **Analysis tasks** — spreadsheet or Python analysis with a written interpretation.
- **Design tasks** — wireframes, prototypes and design rationale.
- **Project reports** — capstone documentation following the [Project Template](../../07-learner-portfolio/project-template.md).

## Assignment design checklist

- Clear title and grade level
- Learning objectives
- Context and task description
- Success criteria / rubric link
- Required deliverables
- Suggested tools and resources
- Deadline and submission format
- Academic integrity reminder (cite sources, verify AI output)

## Suggested assignments by grade

| Grade | Assignment examples |
|---|---|
| 6 | Personal introduction document; technology timeline; digital safety poster |
| 7 | Formatted school report; referenced community research; Scratch story |
| 8 | HTML personal page; Python quiz; network diagram; AI comparison write-up |
| 9 | Portfolio webpage; attendance analysis; phishing analysis guide; team project |
| 10 | Data analysis report; library database; product prototype; innovation proposal |
| 11 | Capstone project and report with testing evidence and reflection |

## Feedback

Return assignments with specific feedback linked to the rubric and competency levels. Ask learners to act on feedback through an improvement step where practical.

Projects carry a suggested 25% weighting and documentation/presentation 10% in the [Assessment Framework](../../00-programme-framework/assessment-framework.md).
