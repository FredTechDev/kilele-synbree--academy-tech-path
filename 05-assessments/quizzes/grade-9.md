# Grade 9 Quiz — Explore the Technology Ecosystem

**Time:** 18 minutes · **Format:** multiple choice, code reading, short answer

## Questions

1. Which Python collection stores key-value pairs?
   a) List  b) Dictionary  c) Tuple  d) String

2. What does `len(marks)` return?
   a) The largest mark
   b) The average mark
   c) The number of items
   d) The sum of marks

3. Which CSS property changes the text colour?
   a) `background`  b) `color`  c) `font-size`  d) `margin`

4. In Git, what does a **commit** do?
   a) Deletes the repository
   b) Saves a snapshot of tracked changes
   c) Publishes the project automatically
   d) Renames a branch

5. Which SQL command retrieves data from a table?
   a) `GET`  b) `SELECT`  c) `READ`  d) `FIND`

6. What is phishing?
   a) A type of chart
   b) A trick to obtain sensitive information by pretending to be trustworthy
   c) A programming language
   d) A network cable

7. Code reading: what is the value of `total`?
   ```python
   total = 0
   for number in [2, 4, 6]:
       total += number
   ```

8. A wireframe is mainly used to:
   a) Store database records
   b) Plan the layout of a screen
   c) Compile Python code
   d) Configure a router

9. Short answer: why should AI-assisted research output be verified?

## Answer key

1. **b** — a dictionary stores key-value pairs.
2. **c** — the number of items.
3. **b** — `color`.
4. **b** — a commit records a snapshot with a message.
5. **b** — `SELECT`.
6. **b** — phishing uses deception to obtain information.
7. `12`.
8. **b** — wireframes plan layout before detailed design.
9. AI can produce incorrect or biased information and may cite sources inaccurately; verification protects accuracy and academic integrity.
