# Grade 6 Quiz — Discover Technology

**Time:** 10 minutes · **Format:** multiple choice and short answer  
**Learning area:** computer awareness, file management, internet safety, sequencing

## Questions

1. Which of these is **software**?
   a) Monitor  b) Keyboard  c) Word processor  d) Printer

2. Which device is used to **hear** sound from a computer?
   a) Microphone  b) Speakers  c) Mouse  d) Storage drive

3. What does a processor do?
   a) Stores files permanently
   b) Displays pictures
   c) Processes instructions
   d) Connects to the internet

4. Which file extension is most likely a document?
   a) `.jpg`  b) `.mp3`  c) `.docx`  d) `.png`

5. What should you do if a message online asks for your password?
   a) Send it immediately  b) Share it with a friend  c) Tell a trusted adult  d) Click every link

6. A browser is different from a search engine because a browser:
   a) Only shows videos
   b) Displays web pages; a search engine finds them
   c) Stores passwords
   d) Is installed on phones only

7. Put these steps in the correct order for saving a file:
   `Choose a name → Open the document → Click Save → Choose a folder`

8. Short answer: give one example of how technology helps a farmer or a doctor.

## Answer key

1. **c** — a word processor is a program; the others are hardware.
2. **b** — speakers output sound; a microphone inputs sound.
3. **c** — the processor carries out instructions.
4. **c** — `.docx` is a document format.
5. **c** — never share passwords; ask a trusted adult.
6. **b** — the browser displays pages; the search engine finds them.
7. Open the document → Choose a name → Choose a folder → Click Save.
8. Any relevant example, e.g. weather information for farmers, or digital records for doctors.
