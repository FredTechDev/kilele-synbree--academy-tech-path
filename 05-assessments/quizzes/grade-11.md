# Grade 11 Quiz — Build and Specialize

**Time:** 25 minutes · **Format:** multiple choice, short answer, scenario

## Questions

1. Which deliverable is **required** for a Grade 11 capstone project?
   a) A problem statement  b) A social media page  c) A paid advertisement  d) A password

2. In a Git workflow, a **pull request** is used to:
   a) Delete a repository
   b) Propose changes for review before merging
   c) Install Python
   d) Create a database

3. Testing with unusual inputs mainly checks:
   a) Colour choices
   b) How the solution handles edge cases
   c) Font size
   d) The number of slides

4. Which is an example of technical documentation?
   a) A README explaining how to run a project
   b) A random screenshot
   c) A personal diary
   d) A music file

5. In a database-driven application, a foreign key:
   a) Locks the database file
   b) Links a record to a record in another table
   c) Speeds up the processor
   d) Replaces a password

6. Which statement about responsible AI is correct?
   a) AI output is always accurate
   b) AI systems can reflect bias and need human oversight
   c) AI should make all decisions without review
   d) Personal data should always be shared with AI tools

7. Scenario: your capstone uses learner marks. What should you do first?
   a) Publish the marks online
   b) Anonymize the data and get permission
   c) Delete the documentation
   d) Skip testing

8. Short answer: explain the difference between a syntax error and a logical error.

9. Short answer: give two pieces of evidence you would include in a portfolio project entry.

## Answer key

1. **a** — a problem statement is one of the required capstone deliverables.
2. **b** — pull requests propose changes for review.
3. **b** — edge cases and unusual inputs.
4. **a** — a README is standard technical documentation.
5. **b** — a foreign key references another table.
6. **b** — bias and oversight matter; outputs require verification.
7. **b** — protect privacy: anonymize and obtain permission.
8. A syntax error breaks the language rules and stops the program; a logical error runs but produces the wrong result.
9. Any two, e.g. source code link, screenshots, test results, demo video, design notes, teacher feedback, reflection.
