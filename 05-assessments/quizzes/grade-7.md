# Grade 7 Quiz — Develop Digital Competence

**Time:** 12 minutes · **Format:** multiple choice, short answer, practical question

## Questions

1. Which spreadsheet formula adds the values in cells A1 to A3?
   a) `=COUNT(A1:A3)`  b) `=SUM(A1:A3)`  c) `=TOTAL(A1:A3)`  d) `=ADD A1 A3`

2. What is the main purpose of a header and footer in a document?
   a) To make the font bigger
   b) To repeat information on every page
   c) To delete old text
   d) To add charts

3. Which of these is the **best** sign that a website may be reliable?
   a) It has bright colours
   b) It appears first in search results
   c) The author is identified and the information is supported by other sources
   d) It has many advertisements

4. Copying someone's work without credit is called:
   a) Formatting  b) Plagiarism  c) Compression  d) Backing up

5. In a flowchart, which shape usually represents a decision?
   a) Rectangle  b) Oval  c) Diamond  d) Circle

6. In visual programming, an **event** is:
   a) A variable
   b) Something that triggers a script, such as a click
   c) A loop that never ends
   d) A saved file

7. Short answer: why should you create a backup of important schoolwork?

8. Practical: write pseudocode for deciding whether a learner passed an examination with 50 as the pass mark.

## Answer key

1. **b** — `=SUM(A1:A3)`.
2. **b** — headers and footers repeat on every page.
3. **c** — authorship and corroboration are stronger signals than appearance or rank.
4. **b** — plagiarism.
5. **c** — a diamond represents a decision.
6. **b** — events trigger blocks of code.
7. To recover work if a device fails, a file is deleted, or storage is lost.
8. Any logical version, e.g. `INPUT mark; IF mark >= 50 THEN print "Pass" ELSE print "Fail"`.
