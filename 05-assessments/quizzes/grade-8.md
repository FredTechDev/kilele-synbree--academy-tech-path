# Grade 8 Quiz — Understand and Create

**Time:** 15 minutes · **Format:** multiple choice, code reading, short answer

## Questions

1. Which Python statement displays text on the screen?
   a) `read()`  b) `print()`  c) `show()`  d) `input()`

2. What does `input()` do in Python?
   a) Prints a message
   b) Gets a value from the user
   c) Deletes a variable
   d) Opens a file

3. What is stored in the variable `x` after `x = 7 + 3`?
   a) `7`  b) `3`  c) `10`  d) `"7+3"`

4. Which HTML tag creates a hyperlink?
   a) `<p>`  b) `<img>`  c) `<a>`  d) `<h1>`

5. In a database table, a **record** is:
   a) A column
   b) One row of information about one item
   c) A file extension
   d) A type of chart

6. Which device connects a local network to another network such as the internet?
   a) Router  b) Monitor  c) Keyboard  d) Printer

7. Which of these is a conductor?
   a) Plastic  b) Rubber  c) Copper  d) Glass

8. Code reading: what does this program print?
   ```python
   for i in range(3):
       print(i)
   ```

9. Short answer: give one limitation of AI-generated information.

## Answer key

1. **b** — `print()`.
2. **b** — it reads user input.
3. **c** — `10`.
4. **c** — `<a href="...">`.
5. **b** — a record is one row; a field is a column.
6. **a** — a router connects networks.
7. **c** — copper conducts electricity.
8. It prints `0`, `1`, `2` on separate lines — `range(3)` stops before 3.
9. Any valid point, e.g. it can be inaccurate, biased or outdated, and must be verified.
