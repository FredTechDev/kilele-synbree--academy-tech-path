# Grade 10 Quiz — Discover Technology Pathways

**Time:** 20 minutes · **Format:** multiple choice, code reading, short answer

## Questions

1. In object-oriented programming, a **class** is best described as:
   a) A loop
   b) A blueprint for creating objects
   c) A database query
   d) A network device

2. Which SQL clause filters rows?
   a) `WHERE`  b) `ORDER BY`  c) `GROUP BY`  d) `INSERT`

3. The three goals of security are usually confidentiality, integrity and:
   a) Availability  b) Popularity  c) Speed  d) Simplicity

4. What does an API allow?
   a) Hardware to cool down
   b) Different software applications to communicate
   c) A computer to start
   d) A browser to store passwords

5. Which is a good data-ethics practice?
   a) Publishing personal learner data
   b) Reusing data without permission
   c) Anonymizing data and documenting its source
   d) Ignoring inaccurate records

6. In machine learning, the data used to teach a model is called:
   a) Training data  b) Output data  c) Cache  d) Firmware

7. What does DNS do?
   a) Encrypts files
   b) Translates domain names into IP addresses
   c) Stores spreadsheets
   d) Controls a robot

8. Code reading: what does this function return?
   ```python
   def double(x):
       return x * 2
   ```

9. Short answer: why should cybersecurity practice use isolated or authorized environments?

## Answer key

1. **b** — a class is a blueprint; an object is an instance.
2. **a** — `WHERE` filters rows.
3. **a** — availability.
4. **b** — APIs let applications communicate.
5. **c** — anonymize and document sources.
6. **a** — training data.
7. **b** — DNS resolves names to IP addresses.
8. It returns twice the argument, e.g. `double(4)` returns `8`.
9. Testing without permission can harm real systems and may be illegal; authorized labs keep learning safe and ethical.
