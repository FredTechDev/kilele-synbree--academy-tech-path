# Quizzes

*Kilele TechPath — Assessment and Evaluation Framework*

Short quizzes check conceptual understanding without replacing practical assessment. They should be brief, varied and age-appropriate.

## Purpose

- Confirm understanding of key terms and concepts.
- Reveal misconceptions early.
- Reinforce safety and responsible technology messages.

## Quiz guidelines

- Keep quizzes short (5–10 questions).
- Mix question types: multiple choice, true/false, matching, short answer.
- Use familiar contexts from learners' environments.
- Include at least one practical or scenario-based question where possible.
- Give feedback that explains why an answer is correct.

## Suggested quiz topics by grade

| Grade | Topics |
|---|---|
| 6 | Technology in daily life; computer types; input/output devices; hardware vs software; file extensions; online safety scenarios |
| 7 | Spreadsheet formulas; document formatting; reliable sources; copyright/plagiarism; algorithms and flowcharts |
| 8 | Programming vocabulary; variables and conditions; HTML tags; database terms; network devices; circuits; AI basics |
| 9 | Python syntax; HTML/CSS/JavaScript concepts; Git terms; data interpretation; phishing and authentication; UI/UX terms |
| 10 | OOP and functions; SQL joins; security principles (CIA); data ethics; cloud terms; SDLC |
| 11 | Pathway-specific concepts; testing and deployment; data validation; professional collaboration |

## Question bank structure

Each quiz file should include:
1. Quiz title and grade
2. Learning objectives assessed
3. Questions with answer key
4. Suggested time and marking
5. Feedback notes

## Recording results

Record conceptual understanding scores in the [Technology Passport](../../07-learner-portfolio/technology-passport.md). Conceptual understanding carries a suggested 20% weighting in the [Assessment Framework](../../00-programme-framework/assessment-framework.md).
