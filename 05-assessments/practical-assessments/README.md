# Practical Assessments

*Kilele TechPath — Assessment and Evaluation Framework*

Practical assessments measure whether learners can actually perform technology tasks, not just describe them.

## Purpose

- Observe learners performing real tasks.
- Assess practical competence and problem-solving.
- Provide evidence for the portfolio and technology passport.

## Methods

- Practical demonstrations
- Observed tasks with a checklist
- Task-based challenges (e.g. "create a folder structure", "debug this program")
- Recorded demonstrations or screenshots
- Oral explanation of the process

## Suggested practical assessments by grade

| Grade | Task examples |
|---|---|
| 6 | Operate a computer; create and organize files; label hardware; write step-by-step instructions |
| 7 | Format a report; build a spreadsheet with formulas; create a Scratch story; draw a flowchart |
| 8 | Write a Python calculator; build an HTML page; draw a network diagram; build a supervised LED circuit |
| 9 | Build a Python grade program; publish a GitHub repository; analyze a dataset; design a network |
| 10 | Develop an inventory app; write SQL queries; analyze a public dataset; complete a lab exercise |
| 11 | Demonstrate a capstone project; explain tests; review code or design decisions |

## Assessment considerations

- Provide clear task instructions and success criteria.
- Observe the process as well as the final product.
- Allow learners to explain their decisions.
- Record evidence (screenshots, code, recordings, checklists).
- Apply the [Practical Project Rubric](../rubrics/README.md) to larger tasks.
- Use the [Competency Levels](../../00-programme-framework/competency-framework.md) (Emerging → Advanced).

## Safety note

Cybersecurity and electronics practicals must use approved, simulated or explicitly authorized environments and safe educational equipment.

Practical exercises carry a suggested 25% weighting and problem-solving challenges 15% in the [Assessment Framework](../../00-programme-framework/assessment-framework.md).
