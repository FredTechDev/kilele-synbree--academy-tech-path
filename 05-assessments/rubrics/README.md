# Rubrics

*Kilele TechPath — Assessment and Evaluation Framework*

## Practical project rubric (100 marks)

| Criterion | Marks | What to look for |
|---|---:|---|
| Understanding of the problem | 15 | Clearly states the problem, users and purpose |
| Planning and design | 15 | Requirements, plan, flowchart/design or architecture present |
| Technical implementation | 25 | Solution works and uses appropriate concepts and tools |
| Creativity and innovation | 10 | Original thinking and thoughtful choices |
| Testing and improvement | 15 | Tests performed, results recorded, improvements made |
| Documentation | 10 | Clear, complete and organized documentation |
| Presentation | 10 | Clear explanation and confident demonstration |
| **Total** | **100** | |

## Competency levels

| Level | Name | Description |
|---|---|---|
| 1 | Emerging | Recognizes basic concepts but requires significant guidance |
| 2 | Developing | Performs basic tasks with some assistance |
| 3 | Competent | Independently applies concepts to familiar problems |
| 4 | Proficient | Adapts knowledge to unfamiliar challenges; strong practical understanding |
| 5 | Advanced | Independently develops, evaluates and improves solutions; explains decisions |

These levels describe **learning progress, not fixed intelligence or ability**.

## Assessment category weightings

| Category | Suggested weighting |
|---|---:|
| Conceptual understanding | 20% |
| Practical exercises | 25% |
| Projects | 25% |
| Problem-solving challenges | 15% |
| Documentation and presentation | 10% |
| Reflection and participation | 5% |
| **Total** | **100%** |

Weightings may be adapted to applicable school assessment requirements.

## Using the rubric

1. Share the rubric before the task begins.
2. Assess both process and product.
3. Record marks and comments in the [Technology Passport](../../07-learner-portfolio/technology-passport.md).
4. Use comments to set a specific next learning goal.
