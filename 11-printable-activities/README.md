# Printable and Unplugged Activities

*Technology learning that needs no computer and no internet — aligned with the [Accessibility and Inclusion](../TECH-PATH-CURRICULUM.md) guidance.*

These activities are designed for:

- Classrooms with shared or limited devices
- Days with no connectivity
- Introduction lessons before learners open a computer
- Homework that can be done on paper

## Activities

| Activity | Grade band | Concepts |
|---|---|---|
| [Step-by-Step Instructions](grade-6-sequencing.md) | 6–7 | sequencing, algorithms, precision |
| [Flowchart Challenge](grade-7-flowcharts.md) | 7–9 | decisions, conditions, flowcharts |
| [Algorithm Debug Hunt](grade-8-algorithms.md) | 8–11 | debugging, logic, testing |

## How to use

1. Print one worksheet per learner or pair.
2. Give a short demonstration first (see [Lesson Plans](../06-teacher-resources/lesson-plans/README.md)).
3. Let learners work individually, then compare answers in pairs.
4. Use the teacher notes at the bottom of each sheet for feedback.
5. Record evidence in the [Technology Passport](../07-learner-portfolio/technology-passport.md).

## Tips

- Ask learners to explain their reasoning aloud — this builds computational vocabulary.
- Accept more than one correct solution when the logic is sound.
- Follow up with the matching [coding challenge](../10-challenges/README.md) when devices are available.
