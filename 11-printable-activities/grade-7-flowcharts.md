## Goal

Represent a decision process using a flowchart.

## Shapes reminder

- **Oval** — start / finish
- **Rectangle** — an action
- **Diamond** — a decision (yes / no)
- **Arrow** — the direction of flow

## Task 1 — Examination result

Draw a flowchart that decides whether a learner has passed with a pass mark of 50.

```
          ( Start )
              |
        [ Input mark ]
              |
          < mark >= 50 >
         /             \
      yes               no
       |                 |
  [ Print "Pass" ]  [ Print "Fail" ]
       \                 /
          ( Finish )
```
