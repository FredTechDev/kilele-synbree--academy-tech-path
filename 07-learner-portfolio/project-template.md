# Project Template

*Use one copy per project. For Grade 11, this becomes the capstone report.*

```markdown
# [Project title]

- **Learner:**
- **Grade:**
- **Date:**
- **Primary pathway (Grade 11):**
- **Complementary pathway (Grade 11):**

## 1. Problem statement
What problem does this project address?

## 2. Background and motivation
Why does this problem matter? Who is affected?

## 3. Target users
Who will use or benefit from this solution?

## 4. Requirements
- Functional requirements (what it must do)
- Non-functional requirements (usability, accessibility, security, performance)

## 5. Design or architecture
Include diagrams, wireframes, flowcharts or circuit designs where relevant.

## 6. Tools and technologies
List programming languages, applications, hardware and services used.

## 7. Implementation or prototype
Describe what was built and how. Include key code/design decisions.

## 8. Testing and evaluation
- Tests performed:
- Results:
- Evidence (screenshots, logs, recordings):

## 9. Challenges encountered
What difficulties arose and how were they handled?

## 10. Improvements
What would you change or add with more time?

## 11. Project documentation
Repository/link, files, and how to run or view the project.

## 12. Final presentation
Summary of the demonstration and feedback received.

## 13. Reflection on learning
What did I learn about the technology and about myself as a learner?
```

## Reminders

- Cite sources and respect copyright.
- Verify AI-generated content and maintain academic integrity.
- Keep evidence for the [Technology Passport](technology-passport.md).
- Assess your work with the [Practical Project Rubric](../05-assessments/rubrics/README.md).
