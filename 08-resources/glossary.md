# Glossary

*Key terms used across the Kilele TechPath curriculum.*

| Term | Meaning |
|---|---|
| Algorithm | A step-by-step set of instructions for solving a problem or completing a task. |
| Abstraction | Focusing on important information while hiding unnecessary detail. |
| API | An interface that allows software applications to communicate with each other. |
| Authentication | Verifying the identity of a user or system. |
| Backup | A copy of data kept so it can be restored if the original is lost or damaged. |
| Bug | An error in a program that causes it to behave unexpectedly. |
| Computational thinking | Breaking problems down, recognizing patterns, abstracting and designing logical solutions. |
| Decomposition | Breaking a large problem into smaller, manageable parts. |
| Debugging | Finding and fixing errors in a program or system. |
| Digital footprint | The trail of information left online through activity and communication. |
| DNS | The Domain Name System — translates human-readable domain names into IP addresses. |
| Flowchart | A diagram that shows the steps and decisions in a process. |
| Function | A reusable block of code that performs a specific task. |
| Hardware | The physical parts of a computer or device. |
| HTML | HyperText Markup Language — the standard language for structuring web pages. |
| CSS | Cascading Style Sheets — used to style and lay out web pages. |
| JavaScript | A programming language used to add interactivity to web pages. |
| IP address | A numeric label that identifies a device on a network. |
| LAN | Local Area Network — a network covering a small area such as a classroom or school. |
| Loop | A programming structure that repeats instructions. |
| Malware | Software designed to harm or exploit devices and data. |
| Phishing | Attempting to obtain sensitive information by pretending to be a trustworthy source. |
| Pseudocode | An informal, human-readable description of an algorithm. |
| Router | A device that connects networks and directs data between them. |
| Software | Programs and instructions that tell hardware what to do. |
| SQL | Structured Query Language — used to work with databases. |
| Switch | A device that connects devices within a network. |
| Variable | A named storage location for a value in a program. |
| UI / UX | User Interface / User Experience — how a product looks, feels and works for users. |
| Version control | Tracking changes to files so previous versions can be recovered and teams can collaborate. |
| Wi-Fi | Wireless technology that allows devices to connect to a network without cables. |
